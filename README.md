# Split View Diff

Chrome 분할 보기(Split View)로 나란히 띄운 두 탭의 텍스트를 비교하고, 차이 나는 부분을 색으로 표시하는 확장 프로그램입니다.

- 빨간색: 왼쪽 탭에만 있는 내용
- 초록색: 오른쪽 탭에만 있는 내용
- 진한 색은 문단 안에서 바뀐 단어, 연한 색은 문단 전체가 한쪽에만 있는 경우입니다.

## 설치

1. `chrome://extensions` 를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.

## 사용법

1. 탭 두 개를 분할 보기로 엽니다 (탭 우클릭 → 분할 보기에 추가).
2. 툴바의 확장 아이콘을 누르고 **비교**를 누르거나, `Alt+Shift+V`를 누릅니다. 첫 번째 차이로 자동 이동합니다.
3. **◀ 이전** / **다음 ▶** (또는 `Alt+Shift+↑` / `Alt+Shift+↓`)로 차이 사이를 이동합니다. 양쪽 탭이 함께 이동하고, 현재 차이는 파란 테두리로 표시됩니다. 한쪽에만 있는 내용이면 반대쪽은 그 내용이 들어갔어야 할 자리로 이동합니다.
4. 표시를 없애려면 **지우기**를 누릅니다.

### 옵션

- **대소문자 무시**: 대소문자만 다른 경우 같은 내용으로 봅니다. 비교 결과가 있을 때 바꾸면 자동으로 다시 비교합니다.
- **왼쪽/오른쪽 스크롤 동기화**: 한쪽을 스크롤하면 반대쪽도 따라 움직입니다. 비교한 뒤에는 같은 문단끼리 맞춰서 움직이므로, 한쪽에 내용이 추가돼 길이가 달라도 어긋나지 않습니다. 비교 전에는 스크롤 비율로 맞춥니다.

단축키는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다. 팝업 아래쪽에 실제로 등록된 단축키가 표시되며, 비어 있는 항목("미지정")이 있으면 **단축키 설정 열기** 버튼이 나타납니다. Chrome은 자기 자신의 단축키와 겹치는 키는 확장에 배정하지 않으며, 다른 확장이 먼저 쓰는 키도 배정하지 않습니다. 최신 Chrome에서는 `Alt+Shift+N`(새 분할 탭), `Alt+Shift+C`/`P`/`X`/`Z`/`W`(탭 그룹), `Alt+Shift+A`/`B`/`I`/`R`/`T`도 Chrome 기본 단축키입니다. 그런 경우 팝업에 "미지정"으로 표시되므로 다른 키를 직접 지정하면 됩니다.

## 동작 방식

- 각 탭의 보이는 텍스트를 블록(문단, 셀, 목록 항목 등) 단위로 추출합니다.
- 두 블록 목록을 Myers diff로 비교합니다. 바뀐 블록끼리 단어 단위로 한 번 더 비교합니다.
- 공백 차이는 무시합니다.

## 제한 사항

- 텍스트만 비교합니다. 이미지와 스타일 차이는 비교하지 않습니다.
- iframe 안의 내용과 `chrome://`, 웹 스토어 페이지는 비교할 수 없습니다.
- 페이지 내용이 바뀌면 다시 **비교**를 눌러야 합니다.
- 스크롤 동기화는 페이지 전체 스크롤만 따라갑니다. 페이지 안의 별도 스크롤 영역(내부 패널 등)은 동기화하지 않습니다.
- 탭 API에 `splitViewId`가 있는 최신 Chrome에서만 동작합니다.
